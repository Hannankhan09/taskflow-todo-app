# TaskFlow — Mini Interactive JavaScript App
**Developer:** Hannan Khan | **Internship:** Task 2

## Overview
TaskFlow is a responsive to-do list app made with HTML, CSS and vanilla JavaScript. It demonstrates DOM manipulation and browser storage without requiring an API.

## Features
- Add tasks, mark them complete, and delete them
- Filter all, active, and completed tasks
- Clear completed tasks
- Dynamic task counts and progress bar
- Save tasks in `localStorage`
- Responsive desktop and mobile layout

## Run locally
Download/clone the repository and open `index.html` in a modern browser. No build tools or API key are needed.

## DOM manipulation demonstrated
`querySelector`, `createElement`, `append`, `replaceChildren`, `addEventListener`, `classList`, and updates to `textContent` and `style.width`.
